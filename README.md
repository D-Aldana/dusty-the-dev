# 🌐 Dustin Aldana — Portfolio Website

Welcome to my personal portfolio website — a space where I showcase my work, share my story, and highlight the skills I’ve built as a full-stack developer.

🔗 **Live Site:** [https://www.builtbydustin.dev](https://www.builtbydustin.dev)

---

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Emotion](https://emotion.sh/)
- **Animations:** [GSAP](https://gsap.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **SEO:** Custom meta tags, Open Graph, robots.txt, sitemap.xml, Google Analytics
- **Integrations:** GitHub, LinkedIn, Instagram

---

## 💡 Features

- Fully responsive and mobile-friendly design
- Smooth scroll and animation effects
- SEO optimized with Open Graph + sitemap
- About, Project, Timeline, and Contact sections
- Dynamic rotating text and interactive icons

---

## 🧠 Inspiration

This site is more than just a portfolio. It’s my digital calling card.
I built it to reflect **my personality** - clean, thoughtful, and a little goofy.

## 📦 Local Development

To run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/D-Aldana/built-by-dustin.git

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
